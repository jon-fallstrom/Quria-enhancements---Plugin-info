1. Scope and purpose

This policy describes how the Quria Enhancements extension for Microsoft Edge (the “Extension”) handles information. The Extension's single purpose is to improve staff workflows and usability in Axiell Quria through optional, user-facing interface and keyboard enhancements.

The Extension is independently maintained by Jon Fällström and Vidar Kjaerstadius. It is not affiliated with, endorsed by, or produced by Axiell or Quria. This policy does not replace the privacy policies of Axiell, the user's employer, library, municipality, or other Quria operator.

2. Information the Extension handles

Quria website content

To provide its selected features, the Extension reads and modifies information already displayed in the current Quria page in Microsoft Edge. Depending on the page and enabled feature, this may include patron names, identifiers, contact information, circulation information, search results, form values, branch information, collection information, and other Quria interface content.

Some optional features transiently process particularly sensitive field values. For example, the Extension can validate a national identity number entered as a patron search and reuse it in the add-patron form, use a patron's name and entered contact details to display local form suggestions or summaries, and inspect the length of a patron PIN field to move focus to its confirmation field. These values are processed only in the current page and are not placed in extension storage or transmitted to the developers.

The Extension does not copy patron or circulation records into extension storage. Configuration values that the user explicitly chooses from Quria, such as favorite school names and facet labels, are the limited exceptions described under “Local storage” below; they do not include patron or circulation record values.

User input and interactions

The Extension responds to user-directed keyboard shortcuts, buttons, searches, and form interactions to provide its features. These interactions are not sent to the developers and are not used to build profiles, measure behavior, or provide advertising.

Local storage

The Extension may store the following information in the Microsoft Edge profile's local extension storage:

  • Whether the user accepted the Extension's privacy notice and whether the Extension is enabled.
  • Enabled features, theme, navigation, print, and other interface preferences.
  • User-created reminder titles, schedules and completion state, and library or desk configuration. Users should not put patron information in reminder titles.
  • Favorite school names, grouped under the corresponding Quria tenant hostname.
  • Locked facet labels and named facet favorites, grouped under the corresponding Quria tenant hostname.
  • Identifiers for the add-patron fields that the user has chosen to highlight; these identify field types and do not contain the values entered in those fields.
  • A generated feature catalogue and non-personal version metadata used to display the Extension's built-in documentation.

A non-personal, per-tab value may also be stored temporarily to remember that a branch reminder was dismissed. That value lasts only for the relevant Microsoft Edge tab session. When the Extension is first installed, the numeric IDs of Quria tabs that were already open can be held temporarily in extension session storage so the welcome page can tell the user which tabs need to be reloaded. Those IDs are removed when no longer needed.

Information the Extension does not store or collect for the developers

The Extension is not designed to read Quria staff login passwords, authentication cookies, or authentication tokens, and it does not store them. It does not store patron PIN values, national identity numbers, contact details, search terms, barcodes, filled form values, payment information, or financial information. It does not contain analytics, advertising, fingerprinting, or cross-site tracking technology.

System clipboard

If the user explicitly selects the copy function for a pick list, the Extension writes the selected titles to the operating system clipboard. It does not read the clipboard's existing contents or transmit copied titles.

3. How information is used

Information is used only on the user's device and only as necessary to provide or maintain the Extension's disclosed user-facing features. It is not used for advertising, profiling, credit decisions, marketing, resale, unrelated research, or any purpose unrelated to the Extension's single purpose.

4. Network activity and data sharing

The Extension does not operate a developer backend and does not transmit Quria content or locally stored settings to the developers, analytics services, advertising services, data brokers, or unrelated third parties. The developers therefore do not have access to information processed locally by the Extension.

When a user invokes a feature, the Extension may interact with controls in the Quria interface. This can cause Quria to make its normal HTTPS application requests to the Quria service, in the same way that the corresponding manual action would. Those requests are part of Quria and are governed by the agreements and privacy practices of Axiell and the organization operating the user's Quria environment.

5. Microsoft Edge permissions

  • Storage: saves the local preferences, reminders, configuration, and favorite schools described above.
  • Access to https://*.quria.axiell.com/*: allows the Extension to provide its features only on Axiell Quria tenant pages.

The Extension does not request access to unrelated websites.

6. Retention and user control

Locally stored preferences remain in the Microsoft Edge profile until the user changes them, uses the Extension's “Clear all data” control, clears extension data through Microsoft Edge, or removes the Extension. Users can disable the Extension without deleting their preferences. Resetting settings retains favorite schools but removes the other choices listed above; “Clear all data” removes all locally stored extension preferences and configuration.

Users can review and change their feature choices, reminders, and configuration on the Extension's Settings page. The data overview in the Extension's Quria menu summarizes locally saved reminders, favorite schools, highlighted patron fields, and facet choices. The Extension does not provide the developers with access to this local data.

7. Security

The Extension is limited to HTTPS Quria tenant addresses, uses packaged code, and does not load executable code from remote servers. Because no system can be guaranteed completely secure, users should keep Microsoft Edge and the Extension updated and disable the Extension if Quria behaves unexpectedly.

8. Microsoft Edge Add-ons data-use disclosure

The Extension's handling of information follows the Developer policies for the Microsoft Edge Add-ons website. Information accessed through Microsoft Edge extension APIs and Quria pages is used only to provide or improve the Extension's disclosed single purpose and user-facing features. It is not sold, used for personalized advertising, or transferred to the developers or unrelated third parties. The developers do not receive this information and therefore do not make it available for human review.

If a user voluntarily provides specific information in a support request, the developers use it only to respond to that request. Users must not provide sensitive Quria data through the public issue tracker. The Extension does not access or transmit support-request content.

9. Changes to this policy

This policy will be updated if the Extension's information-handling practices change. Material changes will also be disclosed prominently in the Extension before the changed handling begins, where required.

10. Contact

Privacy questions and support requests can be submitted through the public Quria Enhancements site issue tracker or the maintainer's GitHub profile. Do not include patron records, authentication information, or other sensitive Quria data in a public issue.
