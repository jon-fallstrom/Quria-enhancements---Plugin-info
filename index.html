About the extension

Small changes that support focused work

The extension works with the Quria interface already open in Microsoft Edge. Its features can be selected individually and are intended to reduce repetitive steps without replacing Quria or an organization's procedures.

Faster navigation

Keyboard shortcuts and contextual navigation aids make frequently used views easier to reach and operate.

Clearer information

Optional highlighting, sorting, filters, and summaries help staff scan relevant interface information.

Flexible setup

Features, appearance, print options, reminders, and selected workflow preferences can be configured locally.

Privacy at a glance

Quria data stays in the user's environment

Local processing

Quria page information is processed in Microsoft Edge to provide visible, user-facing features.

No developer backend

The extension has no developer-operated backend, analytics, advertising, tracking, or remotely hosted code.

User control

Locally stored extension preferences can be changed, reset, or cleared by the user.

Independent project

Designed to complement, not replace, Quria

Quria Enhancements is an independent browser extension for Microsoft Edge, developed and published by Jon Fällström and Vidar Kjaerstadius. It is not developed, approved, sponsored, or distributed by Axiell. It is intended for authorized staff in organizations that use Axiell Quria.

Each organization is responsible for deciding whether the extension may be installed and used, and for ensuring that its use follows the organization's IT, information-security, and data-protection policies. The extension requires an existing, authorized Axiell Quria account; the developers do not provide the account or access to Quria.
